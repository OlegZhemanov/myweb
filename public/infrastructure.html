Infrastructure Overview

This diagram illustrates the cloud infrastructure architecture implemented during my tenure at SberBank. The system is built on SberCloud with Kubernetes at its core, featuring:

  • Multi-region deployment for high availability
  • Service mesh implementation using Istio
  • Automated CI/CD pipelines with Jenkins
  • Infrastructure as Code using Terraform and Ansible
  • Centralized monitoring with Prometheus and Grafana
  • Secure secrets management via HashiCorp Vault

The architecture supports 150+ anti-fraud applications with a 99.9999% SLA, handling 200+ annual releases through automated deployment processes.
